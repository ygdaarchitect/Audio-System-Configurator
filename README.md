# 🔊 Car Audio System & Power Configurator

A simple and interactive web tool designed to help car audio enthusiasts calculate power, current draw, and wiring requirements before building a system.

---

## ✨ Features

* **Component Selection:** Choose different vehicle types, subwoofers, and amplifiers.
* **Real-Time Calculations:** Instantly updates total RMS power and estimated current draw.
* **Electrical Safety Checks:** Warns you if the power draw is too high for your stock alternator.
* **Wiring Recommendations:** Suggests the right wire gauge and fuse size for your setup.

---

## 🛠️ Built With

* **HTML5** - For the structure of the page.
* **CSS3** - For styling and a clean dark-mode design.
* **JavaScript** - For calculations and interactive logic.
